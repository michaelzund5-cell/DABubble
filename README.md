# DABubble

DABubble ist eine moderne Chat-Anwendung auf Basis von Angular.

## Features

- Benutzeranmeldung
- Registrierung
- Channels
- Direktnachrichten
- Nachrichten
- Threads
- Benutzerprofile
- Responsive Benutzeroberfläche

## Technologien

- Angular 22
- TypeScript
- SCSS

## Installation

```bash
npm install
npm start
